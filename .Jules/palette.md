## 2024-07-14 - Keyboard Accessibility on Custom `div` and Icon-only Buttons
**Learning:** The `magic-alphabet` game uses custom `div` elements for its splash screen "button" (`#sigil`) and CSS `::after` content for its icon-only controls (`#resetBtn`, `#themeBtn`). This results in missing keyboard support and missing accessible names for screen readers. Users navigating with a keyboard wouldn't be able to start the game or interact with the controls, and screen reader users wouldn't know what the buttons do.
**Action:** When working on interactive elements in this app's components, always manually add `role="button"`, `tabindex="0"`, `aria-label`, and `onkeydown` handlers for custom elements like `div`s. Also, ensure `:focus-visible` CSS is applied to create clear visual focus rings for all interactive elements, making them distinguishable during keyboard navigation.
