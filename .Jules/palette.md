## 2026-07-20 - Div-based Interactive Elements Accessibility
**Learning:** In the NeuroDivertidos codebase, custom interactive elements (like splash screen sigils) are frequently implemented using `div` elements without native button semantics. This leads to missing ARIA attributes, lack of keyboard navigation (tabbing), missing enter/space key handling, and absence of visual focus indicators, creating significant barriers for users relying on assistive technologies or keyboard navigation.
**Action:** When adding interactive elements or reviewing existing custom controls, always ensure native semantics where possible (e.g., using `<button>`). If a `div` must be used, manually add `role="button"`, `tabindex="0"`, appropriate `aria-label`, `onkeydown` handlers for Enter/Space, and `:focus-visible` CSS styling to guarantee full accessibility.
