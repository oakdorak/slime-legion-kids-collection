## 2024-05-19 - Botones Accesibles con Pseudo-elementos CSS
**Learning:** Esta aplicación utiliza frecuentemente elementos interactivos personalizados basados en div (como el botón de inicio #sigil) y pseudo-elementos ::after para crear botones que solo tienen iconos (como #resetBtn y #themeBtn). Debido a que estos elementos carecen de texto accesible nativo y, a veces, de comportamientos de botón nativos, representan una barrera significativa para los usuarios de lectores de pantalla y teclado.
**Action:** Al trabajar con elementos interactivos basados en div, asegúrate siempre de que tengan role="button", tabindex="0", un aria-label descriptivo y manejadores de eventos de teclado (por ejemplo, onkeydown para Enter/Espacio). Para las etiquetas <button> estándar que dependen únicamente del contenido ::after para su representación visual, proporciona explícitamente un aria-label. Además, añade explícitamente estilos :focus-visible para proporcionar retroalimentación visual clara durante la navegación por teclado.
