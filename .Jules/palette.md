## 2026-07-15 - Accessibility for custom div elements and icon-only buttons
**Learning:** The application extensively uses custom `div` elements for interactive elements like the `#sigil` button in `magic-alphabet/index.html` and icon-only buttons (`#resetBtn`, `#themeBtn`) using `::after` pseudo-elements. These lack native semantics and are inaccessible to screen readers and keyboard users by default. Focus states are also sometimes omitted for these types of custom interactive components.
**Action:** When adding interactive elements, always use native `<button>` tags when possible. If custom elements like `div` are necessary for visual reasons, remember to explicitly add `role="button"`, `tabindex="0"`, `aria-label`, an `onkeydown` handler to simulate `click` on Enter/Space, and explicit `:focus-visible` styles to ensure they are fully usable and visible for keyboard and screen reader users. Always ensure icon-only buttons have descriptive `aria-label` and `title` attributes.
