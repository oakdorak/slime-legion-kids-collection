## 2024-05-19 - Accessible CSS Pseudo-element Buttons
**Learning:** This application heavily uses custom `div`-based interactive elements (like the `#sigil` splash button) and `::after` pseudo-elements to create icon-only buttons (like `#resetBtn` and `#themeBtn`). Because these elements lack native accessible text and sometimes native button behaviors, they pose a significant barrier to screen reader and keyboard users.
**Action:** When working with `div`-based interactive elements, always ensure they have `role="button"`, `tabindex="0"`, a meaningful `aria-label`, and keyboard event handlers (e.g., `onkeydown` for Enter/Space). For standard `<button>` tags that rely solely on `::after` content for visual representation, explicitly provide an `aria-label`. Furthermore, explicitly add `:focus-visible` styles to provide clear visual feedback during keyboard navigation.
