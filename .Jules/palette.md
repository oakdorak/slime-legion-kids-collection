## 2024-07-19 - Splash Screen Accessibility Pattern
**Learning:** The custom `div`-based interactive elements (like splash screens) in this repository require manual addition of ARIA attributes (`role`, `aria-label`, `tabindex`), keyboard event handlers (`onkeydown`), and `:focus-visible` styling to ensure proper keyboard and screen reader accessibility.
**Action:** When adding interactive elements, always include ARIA attributes, keyboard event handlers, and `:focus-visible` styling to ensure proper accessibility.
