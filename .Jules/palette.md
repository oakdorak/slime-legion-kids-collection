## 2025-03-01 - Interactive Divs Accessibility in NeuroDivertidos
**Learning:** In the `mini-zanahoria` module (and likely across the `NeuroDivertidos` repo), interactive elements are frequently built using `div` tags instead of semantic `<button>` elements (e.g., `.grid-quadrant`). This means they inherently lack accessibility features. Relying solely on `click` event listeners leaves keyboard and screen reader users unable to interact with the game mechanics properly.
**Action:** When working on interactive elements within this design system, always verify if they are natively interactive. If custom `div`s are used, manually add `role="button"`, `tabindex="0"`, descriptive `aria-label`s, a visual `:focus-visible` state in CSS, and `keydown` event handlers in JavaScript (capturing "Enter" and "Space" keys) to simulate native button behavior.
