## 2026-07-20 - Accesibilidad en elementos interactivos basados en div
**Learning:** En el código de NeuroDivertidos, los elementos interactivos personalizados (como el botón de inicio) a menudo se implementan usando elementos `div` sin la semántica nativa de un botón. Esto provoca la falta de atributos ARIA, la imposibilidad de navegar con el teclado (tabulación), la ausencia de manejo de las teclas Enter/Espacio y la falta de indicadores visuales de enfoque.
**Action:** Al añadir elementos interactivos o revisar controles personalizados existentes, siempre se debe asegurar la semántica nativa (por ejemplo, usando `<button>`). Si se debe usar un `div`, hay que añadir manualmente `role="button"`, `tabindex="0"`, un `aria-label` adecuado, manejadores `onkeydown` para Enter/Espacio, y estilos CSS `:focus-visible` para garantizar la accesibilidad total.
