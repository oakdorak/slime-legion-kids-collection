## 2026-07-14 - Elementos interactivos personalizados y botones de iconos inaccesibles
**Learning:** Esta aplicación depende frecuentemente de elementos `div` estándar estilizados como elementos interactivos (como `#sigil` que actúa como botón de inicio) y botones vacíos que utilizan pseudo-elementos `::after` de CSS para mostrar iconos gráficos sin texto. Esto presenta un defecto crítico en el patrón de accesibilidad: carecen de interactividad de teclado inherente (`tabindex`, `onkeydown`), no son reconocidos por lectores de pantalla (`role="button"`, `aria-label`) y carecen de estilos de enfoque visual (`:focus-visible`).
**Action:** Al implementar mejoras de UX en esta base de código, se debe auditar explícitamente los elementos `div` que funcionan como botones y los botones de iconos basados en pseudo-elementos para añadir atributos ARIA, soporte de teclado e indicadores visuales de enfoque.
